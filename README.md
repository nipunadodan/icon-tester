# Icon Tester

A simple web tool to preview icons at different sizes with blur effects on light and dark backgrounds.

## Usage

1. Open `index.html` in a browser
2. Upload an icon image
3. Adjust sizes, blur amount, and background colors
4. Preview the icon in both dark and light modes side-by-side

## Built With

- HTML5 Canvas for rendering
- Vanilla JavaScript for interactivity
- CSS for styling

## How It Works

Uses HTML5 Canvas to dynamically render uploaded images at multiple sizes. The canvas context applies blur filters and draws the icon on customizable backgrounds. Real-time event listeners update both dark and light mode canvases whenever settings change.
